# OzoneAI Web (admin ERP)

React + TypeScript (Vite) + Ant Design + AG Grid (later).

## Dev

```bash
npm install
npm run dev
```

App: http://localhost:5173  
API proxy: `/v1`, `/catalog`, `/health` → http://localhost:5080

## Build

```bash
npm run build
```
